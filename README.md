Private repo for the **Matt Huang Thought Partner (MHTP)** — a personalized thought-partner skill for Matt Huang (Paradigm), forked from the Grey engine and tuned to how Matt thinks.

Confidentiality is the first principle: MHTP is a walled container that works only from what Matt feeds it and retains nothing.

## Layout
- `skills/mhtp/` — the skill
  - `SKILL.md` — the engine (forked from grey-team, retuned for Matt)
  - `references/` — `huang-fidelity.md` (his words), `external-observations.md` (others' reads, held lightly), `what-mhtp-would-never-do.md`, + inherited engine posture
  - `deep-sources/` — inherited framework distillations
  - `sources/` — Matt's canon + curated material; `inbox/` is the drop point
  - `OPEN-QUESTIONS.md` — everything unresolved
